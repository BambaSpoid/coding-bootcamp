# Day 002 — Mobile Data Usage Calculator

## Concepts practiced

- Python data types
- Type checking and conversion
- Integer and floating-point numbers
- Mathematical operations
- Number manipulation
- Rounding numbers
- User input

## Challenge

Build a program that analyzes a mobile data bundle and calculates:

- Data consumed
- Percentage of data used
- Average daily usage
- Average cost per GB used
- Remaining data percentage
- Daily budget
