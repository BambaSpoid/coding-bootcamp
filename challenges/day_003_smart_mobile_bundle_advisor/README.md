# Day 003 — Smart Mobile Bundle Advisor

## Overview

A Python command-line application that recommends mobile bundles based on a user's budget, data needs, calling habits, and student status.

## Concepts Practiced

- Conditional statements (`if`, `elif`, `else`)
- Nested conditions
- Logical operators (`and`)
- Comparison operators
- Boolean expressions
- Modulo operator (`%`)
- User input and type conversion
- Basic code refactoring

## Features

- Recommends a mobile bundle based on user preferences.
- Supports four bundles: Mini, Data, Mix, and Max.
- Applies a 20% data bonus for eligible students.
- Handles insufficient budgets.
- Includes an even/odd number checker.

## Available Bundles

| Bundle | Price (FCFA) | Data (GB) |
| ------ | -----------: | --------: |
| Mini   |        1,000 |         2 |
| Data   |        2,000 |        10 |
| Mix    |        3,000 |         8 |
| Max    |        5,000 |        25 |

## How to Run

From the repository root:

```bash
python challenges/day_003_smart_mobile_bundle_advisor/main.py
```
